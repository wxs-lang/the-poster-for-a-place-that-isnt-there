A travel poster for Velmara, a place that does not exist: a white lighthouse on a rose-gold sea stack, a terraced cliff town with its windows lit at golden hour, and a calm turquoise bay with three small wooden boats. The place's name is set into the picture in a vintage poster face; nothing else is written on it.

## Run it

```sh
node main.ts
```

It copies the bundled poster (`poster.jpg`, 1024 by 1024) to `$MAKEFUN_OUTPUT_DIR/entry.png` (`/output` by default). Same bytes every run, no network, no dependencies.
